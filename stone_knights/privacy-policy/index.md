# プライバシーポリシー — Stone Knights

最終更新日: 2026年10月12日 / バージョン: 4

本ポリシーは複数言語で提供される場合がありますが、**日本語版が正文（優先される版）**です。
翻訳版と日本語版の間に齟齬がある場合は、日本語版の内容が優先されます。

**このポリシーは一般的な雛形であり、弁護士による法的レビューを受けたものではありません。**
一般公開（TestFlight内部配信を超えた配布）の前に、内容が実際の実装・運用と一致しているか、
必要であれば専門家に確認してください。

## 1. はじめに

Stone Knights（以下「本アプリ」）は、盤上で石を動かして対戦するボードゲームです。
本ポリシーは、本アプリの利用にあたり収集される情報とその取り扱いについて説明します。

**バージョン4での主な変更:** 本アプリのオンライン対戦機能を廃止したため、オンライン対戦のための
情報（匿名認証・通信の中継・対戦記録）に関する記載を削除しました。あわせて、ゲームの改善と
不具合の把握のために、利用状況とクラッシュの情報を収集する旨を追加しました（第2項）。

## 2. 本アプリが収集する情報

### 端末内にのみ保存される情報

所持している石・コイン・かけら・実績の達成状況・デッキの構成・ストーリーの進行・設定
（BGM/SEのON/OFF、統計送信のON/OFF）は、端末内（PlayerPrefs）にのみ保存されます。
外部へ送信されることはなく、アプリを削除すると消去されます。

本アプリは、氏名・メールアドレス・電話番号・住所などの個人を特定する情報を
一切収集しません。アカウント登録（メールアドレスやパスワードの入力）も不要です。

### 利用状況の情報（Unity Gaming Services Analytics）

ゲームの遊びやすさを改善するため（たとえば、ストーリーのどこで難しすぎて止まってしまうかを
知るため）、Unity Technologies社が提供するUnity Gaming Services（UGS）のAnalyticsを
利用して、次のような利用状況を収集します。

- 選んだモード（ストーリー・CPU対戦・詰め石・遊び方など）
- 対局の開始と終了、対局の結果（勝ち・負け・引き分け・投了）、手数、かかった秒数、
  ストーリーの章、CPUの強さ
- 詰め石の問題の挑戦結果と、かかった秒数
- スタミナが足りずに止まった回数と、スタミナ回復の広告を見た回数

これらは**個人を特定する情報とは紐づきません**。本アプリは氏名・メールアドレス等を収集しないため、
これらの情報から利用者個人を特定することはできません。ただし、Unityの仕組みにより、アプリごと・
端末ごとに自動で発行される匿名の識別子、および端末の機種・OSのバージョン・アプリのバージョン・
言語・おおよその地域などの情報が、あわせて送信されることがあります。

- **同意の後でだけ始めます。** 本ポリシーに同意する前には送信しません。
- **いつでも止められます。** 「設定」の「統計送信」をOFFにすると、以降は送信しません。
- 溜めておいて後から送ることはしません（OFFの間・同意前の操作の記録は破棄されます）。

### クラッシュ・不具合の情報（Unity Cloud Diagnostics）

アプリが予期せず終了した場合に、原因を調べて直すため、Unity Cloud Diagnosticsを利用して
クラッシュの情報（エラーの内容、発生した位置の記録、端末の機種・OSのバージョン・
アプリのバージョン）を収集します。個人を特定する情報は含みません。
クラッシュの情報の送信は、上記の「統計送信」の設定とは別に行われます。

これらの情報はUnity Technologies社によって処理されます。
[Unity Gaming Servicesのプライバシーポリシー](https://unity.com/legal/game-player-and-app-user-privacy-policy)
もあわせてご確認ください。

### Appleが収集する情報

iOSの「設定 > プライバシーとセキュリティ > 解析と改善」で
**「iPhoneの解析を共有」と「Appデベロッパと共有」を有効にしている場合**、Appleがクラッシュや
使用状況の情報を収集し、匿名化・集計された形で当方がApp Store Connect上で参照できることが
あります。これはApple社が提供する仕組みによるもので、当方が直接収集するものではありません。
同じ設定画面からいつでも停止できます。

### 広告のために収集する情報（Google AdMob）

本アプリには、視聴するとコインを獲得できるリワード広告（動画広告）があります。
広告は自動的に表示されることはなく、利用者が広告アイコン（宝箱の絵）をタップして
視聴を選んだ場合にのみ表示されます。表示にはGoogle社が提供するGoogle Mobile Ads SDK
（AdMob）を利用しています。

広告SDKを初期化する前に、GoogleのUser Messaging Platform（UMP）による同意取得
（EU圏等、法令上必要な地域向け）と、iOSでは「Appによるトラッキングの要求」
（App Tracking Transparency）の許可確認を行います。

- 許可した場合、広告ID等の識別子が広告の配信・効果測定のためにGoogleへ送信されることが
  あります。
- 許可しなかった場合、これらの識別子に基づく処理は行われず、広告は非パーソナライズの形で
  配信されます。許可の有無にかかわらず、広告を視聴して報酬を受け取ることは可能です。

収集される情報の詳細は、[Googleのプライバシーポリシー](https://policies.google.com/privacy)
および
[Google Mobile AdsのApp Store向けデータ開示](https://developers.google.com/admob/unity/privacy/data-disclosure)
を参照してください。

## 3. 本アプリが利用していないもの

- Firebase Analytics / Crashlytics — 組み込んでいません（利用状況とクラッシュはUnityのサービスで
  収集しています。上記を参照）
- オンライン対戦のための通信・認証・対戦記録の保存 — 廃止しました
- アプリ内課金 — 組み込んでいません

## 4. 情報の利用目的

- 端末内のデータは、アプリの動作（進捗の保存・復元）のためだけに使用します
- 利用状況の情報は、ゲームの難しさや遊びやすさの改善のためだけに使用します
- クラッシュの情報は、不具合の原因の調査と修正のためだけに使用します
- 広告に関する情報は、リワード広告の配信と、その効果測定のためだけに使用します

## 5. 第三者への提供

第2項に記載の情報は、Unity Technologies社（UGS）およびGoogle社（Google Mobile Ads）
によって、それぞれの会社のプライバシーポリシーに基づき処理されます。上記以外の第三者へ
情報を提供することはありません。

## 6. お子様のプライバシー

本アプリは13歳未満のお子様を対象としていません。13歳未満のお子様から意図的に
情報を収集することはありません。

## 7. 本ポリシーの変更

本ポリシーを変更する場合は、本ページとアプリ内表示のバージョン番号を更新します。
バージョンが変わった場合、次回起動時にアプリ内で改めて同意を求めます。
